# AE Frontend Design

Use this skill for frontend UI work. Prefer the current Codex frontend/design/browser capabilities available in the host environment.

Rules:

- Preserve existing design systems when present.
- Avoid generic layouts and low-effort visual defaults.
- Define validation up front: screenshot, browser interaction, component test, or manual checklist.
- Do not require `agent-browser`; use available Codex browser tooling or Playwright when possible.
